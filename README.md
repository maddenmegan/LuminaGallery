100% English UI • Hyper-Fast AMOLED Gallery • Offline AI OmniSearch (Photos, Videos, Screenshots & PDFs) • Lumina AI Studio Pro • Offline AI People & Faces • Universal Multi-Language OCR • Dual QR Scanner • Biometric Vault.

## Build on Phone with GitHub Actions
1. Create a public GitHub repo `LuminaGallery` with a README.
2. Open **Code -> Codespaces -> Create codespace on main** and upload `LuminaGallery-v3-Final.zip`.
3. Run in Terminal:
   ```bash
   unzip -o *.zip && rm *.zip && git add -A && git commit -m "Build Lumina Gallery Final" && git push
   ```
4. Download `LuminaGallery-Final-APK` from the **Actions** tab and install `app-release.apk`.
